## How to use the web viewer
- Open the Web Viewer link in a desktop browser (WebGL2). Click the scene to capture the mouse.
- **W A S D** to walk, mouse to look, **Space / Shift** for vertical movement, **Esc** to release the mouse.
- To load another model: append `?model=<url>` to the link, or drag and drop a `.ply`, `.splat` or `.ksplat` file onto the page.
